# Photos

Photos are optional. Save a picture in this folder with one of the names below and the site shows it automatically. Where a file is missing, the emoji tile is shown instead.

Use `.jpg` files. Landscape photos about 800 px wide work well; keep each under 200 KB so pages load fast.

| File name | Where it appears |
|---|---|
| `workout-full.jpg` | Home banner and the "Full-body burner" workout |
| `workout-core.jpg` | "Core in 15" workout |
| `workout-legs.jpg` | "Strong legs" workout |
| `workout-cardio.jpg` | "No-kit cardio" workout |
| `recipe-chicken.jpg` | Lemon herb chicken with vegetables |
| `recipe-dal.jpg` | Masoor dal with spinach |
| `recipe-oats.jpg` | Banana peanut oats |
| `recipe-fish.jpg` | Grilled fish with cucumber salad |
| `recipe-chola.jpg` | Chickpea salad bowl |
| `recipe-eggrice.jpg` | Egg and vegetable fried rice |

Free photos you are allowed to use in a project: [Unsplash](https://unsplash.com), [Pexels](https://www.pexels.com) and [Pixabay](https://pixabay.com). Photos you take yourself are fine too. Do not copy photos from Google Images or other people's designs.

The profile picture is different: each visitor adds their own from the Profile page, and it is saved in their browser.
